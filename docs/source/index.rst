=====================
psteros documentation
=====================

psteros is an AiiDA library for reproducible surface thermodynamics.
Quantum ESPRESSO through aiida-quantumespresso is the primary backend; VASP is
available as a tested secondary backend.

The documentation uses a rutile SnO2(110) walkthrough to introduce surface
thermodynamics. It is an illustrative starting point: configure computational
resources and validate scientific settings for your own system.
