=====================
psteros documentation
=====================

psteros is an AiiDA library for reproducible surface thermodynamics.
Quantum ESPRESSO through aiida-quantumespresso is the primary backend; VASP is
available as a tested secondary backend.

The maintained example is the rutile SnO2(110) O/SnO/Sn2O termination study.
Its actual Bohr A100 campaign, including convergence and provenance evidence,
is owned by a Tessera Odyssey Auto project.
